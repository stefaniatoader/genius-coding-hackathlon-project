Project Description
BeatTheHeat is a data-driven heat wave awareness website that visualizes real global temperature data on an interactive 3D globe and provides a complete guide on how to prepare for, survive, and recover from extreme heat. The site is built as a single HTML file with no frameworks — just HTML, CSS, and vanilla JavaScript.

Problem Addressed
Heat is the number one weather-related killer in the United States, yet most people underestimate it and don't know how to protect themselves. Unlike hurricanes or floods, heat waves don't get the same media attention — but they kill more people. BeatTheHeat was built to make that danger visible and give people the information they need to stay safe.

Features

Interactive 3D Globe - powered by real surface temperature measurements from NASA's GLOBE Program API (2024–2026). Every dot is color-coded by temperature and shows the country, location, temperature, and date when hovered.
Extreme Heat Zones Sidebar — a live-ranked list of the 10 hottest regions on Earth with temperatures in both Celsius and Fahrenheit, alongside a color legend.
Preparation Guide - six action cards for before a heat wave, a ten-item checklist for during one, and a section explaining the three stages of heat illness (Heat Cramps, Heat Exhaustion, Heat Stroke) with symptoms and response steps.
Heat Safety Quiz - five questions with instant right/wrong feedback to test heat safety knowledge.
Recovery Tracker - an eight-step checklist with a live progress bar to track recovery after a heat event.
Heat Risk Calculator - enter your current temperature, humidity, outdoor status, and AC access to receive a personal risk level from Low to Extreme.
Before/After India Slider - a draggable comparison map showing India under normal conditions versus the extreme heat wave in Rajasthan, built with SVG clip paths.


Technologies Used

HTML, CSS, JavaScript
globe.gl - 3D globe rendering (built on Three.js)
NASA GLOBE Program API - real surface temperature data
Google Fonts - Playfair Display, Lato
SVG - custom before/after drag slider
Unsplash - hero background image


How to Run the Project
No installation or build step is required.

Download or clone the repository
Open index.html in any modern browser (Chrome, Firefox, Edge, Safari)
An internet connection is required to load the globe library, Google Fonts, and the NASA API data

That's it — the entire site runs from a single file.
